# Пепельный Отряд

Тёмное фэнтези, пошаговый рогалик в браузере (в духе Angry Birds Epic). 12 героев, 46 врагов (30 обычных, 9 элит, 7 боссов), 40 реликвий, 30 событий, 3 акта + финал, мета-прокачка (Кузня), достижения, бестиарий, ежедневный забег, бесконечный режим. Вся графика — SVG.

## Запуск
    python3 -m http.server 8000   # затем открыть http://localhost:8000
    node tests/run.js             # тесты логики
    node tests/sim.js 40 0        # симуляция забегов ботом (кол-во, ascension)

Управление: 1–5 — навыки, Пробел — конец хода, Tab — смена героя, Esc/ПКМ — отмена цели.

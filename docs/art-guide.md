# Арт-гайд «Пепельный Отряд» (SVG)

Тёмное фэнтези, мультяшно-эпичный стиль (как Angry Birds Epic: крупные головы, толстые контуры, выразительные позы), но мрачная палитра.

## Технические правила (обязательно)
- Один персонаж = один файл `.svg`. `viewBox="0 0 200 240"`, **без** width/height. Земля (подошвы) на y=228, центр по x=100. Персонаж занимает ~160x200.
- **Герои смотрят ВПРАВО, враги и боссы смотрят ВЛЕВО.** Боссы можно рисовать крупнее: `viewBox="0 0 320 320"`, земля y=308.
- Контур: `stroke="#14101c"`, `stroke-width` 4–5, `stroke-linejoin="round"`, `stroke-linecap="round"`. Заливки плоские + 1–2 тона тени (градиенты `linearGradient` допустимы), блики светлым.
- **Нельзя**: внешние ресурсы, `<image>`, шрифты/`<text>`, `<script>`, `<style>` с глобальными селекторами, `id` (SVG инлайнятся в одну страницу, id будут конфликтовать). Градиенты — только с уникальным id-префиксом имени файла (например `knight-g1`).
- **Слои для анимации** — группы `<g>` с классами (не id): `part-body` (туловище+ноги), `part-head`, `part-arm-r`, `part-arm-l`, `part-weapon` (оружие, может быть внутри arm-r), опционально `part-extra` (плащ, хвост, крылья). Каждая группа должна иметь `transform-box: fill-box` не нужно — движок сам задаст origin. Рисуйте так, чтобы поворот вокруг плеча/шеи выглядел естественно (рука не отделена от тела пустотой).
- Тень под ногами не рисовать (её добавляет движок).
- Файл должен быть валидным XML, начинаться с `<svg xmlns="http://www.w3.org/2000/svg" viewBox=...>`.

## Палитра
Фон/контур: `#14101c`, `#1e1830`, `#2d2540`. Кожа: `#e8c9a0`, `#b9936b`, зелёная нежить `#7fa07a`, `#4e6b57`, бледная `#c9cbd6`. Металл: `#8e96a8`, `#5d6577`, `#c8d0de`. Акценты по классам: Воин — сталь+красный `#c0392b`; Маг — фиолет `#8e5cf0`, синий `#4aa3ff`, огонь `#ff7a2a`; Support — золото `#f2c94c`, зелёный `#58d68d`; Стрелок/Вор — тёмно-зелёный `#2f6b4f`, кожа `#6b4a2f`. Нежить — зеленоватая бледность; демоны — красный `#d63a3a` + уголь `#2a1a1a`; пустота — `#3b2a6b` + `#b36bff`.

## Иконки
`viewBox="0 0 64 64"`, те же контуры (stroke-width 3), яркий читаемый силуэт, без текста.

## Фоны
`viewBox="0 0 1280 720"`, три плана (дальний, средний, ближний), земля примерно на y≥500 чтобы на ней стояли персонажи. Без персонажей.

## Контроль качества
Каждый файл открыть в Chromium (Playwright; браузер уже установлен, `PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`, не запускать `playwright install`) и посмотреть скриншот (Read картинки). Персонаж должен читаться, быть симпатичным и узнаваемым, не обрезаться по viewBox.
